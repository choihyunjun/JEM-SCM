협력사 납품 안내

발주 확인부터 제품 납입까지

아래 순서대로 발주를 확인하고, 납품서를 만들어 제품과 함께 보내주세요.

1발주 승인2납품서 등록·출력3입고·인수 확인

사진을 누르면 크게 볼 수 있습니다. 화면의 품번·수량은 설명용 예시입니다.

1

발주 확인·승인

발주 관리 → 발주 조회/승인
  1. 품번을 검색하고 품번·수량·납기일을 확인합니다.
  2. 미확인인 발주는 협력사 담당자가 해당 행의 발주확인을 누르고 승인 확인창에 동의합니다.
  3. 상태가 승인완료로 바뀌었는지 확인합니다.
승인완료된 발주는 「납품서 등록/조회」에서 납품 등록할 수 있습니다.

진영에서 등록한 발주를 협력사가 확인·승인한 뒤 납품서를 등록하는 순서입니다. 발주마감 또는 납품가능 수량 0인 건은 등록 대상에 나오지 않습니다.

2

납품서 등록하고 출력하기

납품/입고 관리 → 납품서 등록/조회
수량·LOT 입력 → 추가 → 납품서 생성(등록) → 라벨·납품서 출력

① 하단 목록에서 납품할 품목의 수량을 입력합니다.

같은 품번이 여러 줄이면 ERP 발주번호·순번·납기일을 함께 확인하세요.

입력란입력 방법예시
SNP박스 1개에 들어 있는 수량100
박스실제로 보낼 박스 수3
LOT(생산일)제품의 실제 생산일 선택2026-10-13
SNP 100 × 박스 3 = 납품 수량 300개

② [추가]로 담고, [납품서 생성(등록)]으로 저장합니다.

  1. 총 발행 ≤ 납품가능 수량인지 확인한 뒤 해당 행의 추가를 누릅니다.
  2. 파란색 신규 납품서 등록 대기에서 품번·수량·LOT를 확인합니다. 잘못 담았으면 ×로 지우고 다시 추가합니다.
  3. 납품서 생성(등록)을 누르고 확인창에 동의합니다.
[추가]만 누르면 아직 저장 전입니다. 상단에 새 납품서 번호가 생겨야 등록 완료입니다.

여러 품목은 차례로 추가한 뒤 한 번에 생성하세요. 같은 품번·같은 LOT는 한 납품서에 한 번만 추가할 수 있습니다. 박스별 포장 수량이 다르면 담당자에게 등록 방법을 확인하세요.

③ 상단의 새 납품서에서 라벨과 납품서를 출력합니다.

라벨 → 박스마다 부착

라벨 → 내용 확인 → 인쇄하기
예시: 3박스이므로 라벨도 3장입니다.

납품서 → 제품과 함께 제출

납품서 → 업체·수량·LOT 확인 → 인쇄하기
하단 QR은 진영 담당자가 입고 처리에 사용합니다.

출하 전 확인제품과 라벨의 품번·수량·LOT 일치 · 박스마다 고유 라벨 부착 · 납품서 동봉

라벨은 A4, 배율 100%, 여백 없음/최소로 설정하고 잘림을 확인하세요. 다시 인쇄할 때는 기존 납품서의 출력 버튼을 사용합니다.

수량·LOT를 잘못 등록했다면?
스캔 전이면 납품서를 취소 후 다시 등록합니다. 스캔 후에는 진영 담당자에게 납품서 번호·품번·LOT·수량을 전달하고 정정을 요청하세요.
3

입고 상태·반출 내역 확인하기

납품/입고 관리 → 납품서 등록/조회

입고 상태는 「납품/발행 현황」에서 확인합니다.

상태의미 / 확인할 일
납품서 발행납품서 생성 완료, 입고 처리 전입니다. 라벨·납품서를 출력해 제품과 함께 보내세요.
검사대기검사를 기다리는 품목이 남아 있습니다. 검사 결과를 기다려 주세요.
입고완료검사 또는 무검사 입고 처리가 완료되었습니다. 일부 불량이 있을 수 있으니 반출 내역도 확인하세요.
전량 부적합전체 수량이 불량입니다. 「부적합 / 반출 내역」에서 사유와 반출 진행을 확인하세요.

‘납품서 발행’은 기존 ‘배송중’의 새 명칭입니다. 상태 필터에서 검사대기·입고완료·전량 부적합을 각각 조회할 수 있습니다.

반출된 제품을 실제로 받은 뒤 [인수 확인]을 누릅니다.

  1. 부적합 / 반출 내역에서 납품서 번호·품번·LOT·불량 사유를 확인합니다.
  2. 돌려받은 제품을 반출증과 대조하고, 해당 반출일·수량의 인수 확인을 누릅니다.
  3. 인수 확인 완료 표시를 확인합니다. 확인한 수량만큼 원본 발주의 납품가능 수량이 복구됩니다.
불량 20개 → 반출 5개 → 인수 확인 후 5개 재납품 가능

예시의 수량 표시는 20 / 5 / 0 → 20 / 5 / 5로 바뀝니다. 나머지 15개는 반출 대기이며, 아직 재납품 가능 수량에 포함되지 않습니다.

재납품할 때는 복구된 수량을 확인하고 새 납품서를 작성하세요. 같은 품번이라도 ERP 발주번호·순번을 함께 확인하세요.
담당자에게 확인이 필요한 경우
반출 대기라서 버튼이 없으면 실제 반출을 기다립니다. 받은 수량이 다르거나 「과거 내역 연결 확인 필요」가 보이면 인수 확인 전에 진영 담당자에게 문의하세요.
