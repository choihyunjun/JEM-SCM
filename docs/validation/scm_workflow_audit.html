D01 · 배포운영 DB 복구 적용 상태 현재 코드에 필요한 마이그레이션·테이블·열이 운영 DB와 일치한다.앞선 서버 출력에서 note 열 누락을 확인해 c6083fb 복구 마이그레이션을 제공했다. 이번 검증의 DB는 모델로 새로 만든 SQLite이며, 운영 서버 재배포 후 PASS 결과는 아직 받지 않았다. 범위 밖 / 후속 환경 검증 필요 미검증 높음 서버의 check_deployment PASS와 Gunicorn active를 확인하고 실제 오류 화면을 다시 조회한다. 테스트 통과를 운영 장애 해결로 해석하지 않는다.

  1. 권한과 타 거래 보존: 납품서 출력/태그 발행/LOT API 업체 범위, 발주 연결 검증, 납품서 취소의 발행 이력 삭제 범위를 먼저 수정합니다.

  4. 업무 합의: TAG 재스캔 자동 취소, 인수 확인 후 잔량 복구, 수기 발주 합산, FIFO 예외를 결정합니다.
